# List available built-in pattern names

List available built-in pattern names

## Usage

``` r
list_patterns()
```

## Value

Character vector of pattern names registered in ggpatchy.

## Examples

``` r
list_patterns()
#> [1] "crosshatch" "dots"       "hatch"      "horizontal" "none"      
#> [6] "vertical"   "weave"     
```
